# ⚡ BlacklistScriptx - Roblox Script Hub & Admin System

เว็บไซต์คลังแจกสคริปต์ Roblox สไตล์ Gaming Dashboard (แบบเดียวกับ ScriptBlox / Steam) พร้อมระบบ **Sub2Unlock** และ **ระบบจัดการหลังบ้าน (Admin Panel)** สำหรับเพิ่มสคริปต์ ลบสคริปต์ และเปลี่ยนลิงก์

---

## 🌐 ลิงก์เข้าใช้งานในเครื่อง

* **หน้าเว็บหลักสำหรับคนดู:** [http://localhost:3000/](http://localhost:3000/)
* **หน้าจัดการหลังบ้าน (Admin):** [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

---

## 🛡️ ระบบหลังบ้าน (admin.html) ทำอะไรได้บ้าง?

1. **➕ เพิ่มสคริปต์ใหม่:**
   * กรอกชื่อสคริปต์, ชื่อเกม, คำอธิบาย, ลิงก์รูปภาพ, และโค้ด Lua (Loadstring)
   * ติ๊กเลือกว่า ไร้คีย์ (Keyless), รองรับมือถือ, หรือ PC
   * พอกดบันทึก สคริปต์ใหม่จะไปแสดงที่หน้าเว็บทันที!
2. **📋 จัดการสคริปต์:**
   * ดูรายการสคริปต์ทั้งหมดบนเว็บ พร้อมปุ่มกดลบสคริปต์ที่ไม่ต้องการ
3. **🔗 ตั้งค่าลิงก์ Sub2Unlock:**
   * แก้ไขลิงก์ปุ่มที่ 1 (YouTube หรือ Shopee)
   * แก้ไขลิงก์ปุ่มที่ 2 (เข้าร่วม Discord)
   * แก้ไขลิงก์ปุ่มที่ 3 (คลิป YouTube ล่าสุด)
   * แก้ไขลิงก์ Discord

## 📁 ไฟล์สำคัญในโปรเจกต์

```
roblox-scripthub/
├── index.html       # หน้าบ้าน (หน้าหลัก & คลังสคริปต์)
├── admin.html       # หลังบ้าน (เพิ่ม/ลบสคริปต์ & ตั้งค่าลิงก์)
├── css/style.css    # สไตล์เว็บ
└── js/
    ├── admin.js     # โค้ดระบบหลังบ้าน
    ├── app.js       # โค้ดหน้าบ้าน & ระบบปลดล็อค Sub2Unlock
    ├── config.js    # ข้อมูลลิงก์เริ่มต้น
    └── scripts-data.js # ฐานข้อมูลสคริปต์เริ่มต้น
```
