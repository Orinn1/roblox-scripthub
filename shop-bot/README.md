# 🛒 Discord Shop Bot (Ticket & Slip Verify)
> บอทร้านค้าดิสคอร์ด: ระบบเปิดตั๋วสั่งซื้อสินค้า (Ticket) + ระบบตรวจจับสลิปซ้ำผ่าน QR Code อัตโนมัติ (ฟรี 100% ไม่เสียค่า API)

---

## ✨ ฟีเจอร์เด่น
1. **🎫 ระบบเปิดตั๋วสั่งซื้อสินค้า (Ticket):**
   - ส่งแผงกดเปิดตั๋วในห้อง `🎫 • เปิดตั๋วสั่งซื้อ` ด้วยคำสั่ง `/setup-ticket`
   - เมื่อลูกค้ากดปุ่ม บอทจะสร้างห้องชั่วคราวแบบส่วนตัว (`ticket-ชื่อลูกค้า`) เห็นเฉพาะลูกค้าและแอดมิน
   - มีปุ่ม **[ 💳 ช่องทางชำระเงิน ]**, **[ 🔒 ปิดตั๋ว ]**, **[ 🗑️ ลบห้อง ]**, และ **[ 📜 บันทึก Transcript ]**

2. **🧾 ระบบตรวจสอบสลิปโอนเงิน (ฟรี 100% ไม่ต้องเสียเงินค่า API):**
   - เมื่อลูกค้าส่งรูปสลิปในห้องตั๋ว บอทจะสแกนหา **Mini QR Code** บนสลิปทันที
   - **ดักจับสลิปซ้ำ (Anti-Reuse) 100%:** สลิปที่เคยส่งแล้ว บอทจะปฏิเสธและแจ้งเตือนทันที ป้องกันลูกค้าก๊อปสลิปคนอื่นหรือสลิปเก่ามาวนส่ง
   - **ระบบกึ่งอัตโนมัติปลอดภัยสูง:** บอทแสดงรหัส Ref ID ให้แอดมินดู แล้วมีปุ่ม **`[ ✅ อนุมัติการชำระเงิน ]`** และ **`[ ❌ ปฏิเสธ ]`** แอดมินกดคลิกเดียว บอทจะส่งข้อความปิดบิล + แจกยศลูกค้าให้อัตโนมัติ

---

## 🚀 วิธีตั้งค่าและการเปิดใช้งาน

### 1. ตั้งค่าไฟล์ `.env`
คัดลอกไฟล์ `.env.example` ไปเป็น `.env` หรือเปิดไฟล์ `.env` แล้วกรอกข้อมูล:
```env
# โทเคนของบอทจาก Discord Developer Portal
DISCORD_TOKEN=กรอกโทเคนบอทที่นี่

# ID เซิร์ฟเวอร์ของคุณ
GUILD_ID=123456789012345678

# ID บทบาทของแอดมิน/คนขาย (เพื่อให้มองเห็นตั๋วและกดอนุมัติสลิปได้)
STAFF_ROLE_ID=123456789012345678

# (ไม่บังคับ) ID ยศลูกค้าที่จะแจกให้อัตโนมัติเมื่ออนุมัติสลิป
CUSTOMER_ROLE_ID=

# (ไม่บังคับ) ID หมวดหมู่สำหรับสร้างห้องตั๋ว
TICKET_CATEGORY_ID=

# ข้อมูลการชำระเงินสำหรับแสดงให้ลูกค้า
PROMPTPAY_NUMBER=0xx-xxx-xxxx
PROMPTPAY_NAME=ชื่อบัญชีของคุณ
BANK_NAME=ธนาคารกสิกรไทย
BANK_ACCOUNT=xxx-x-xxxxx-x
```

### 2. วิธีรันบอท
เปิดใช้งานได้ง่ายๆ 2 แบบ:
* **แบบที่ 1 (ง่ายสุด):** ดับเบิ้ลคลิกไฟล์ `run.bat` ในโฟลเดอร์ `shop-bot` ได้เลย
* **แบบที่ 2 (ผ่าน Terminal):**
  ```bash
  cd shop-bot
  npm start
  ```

### 3. การสร้างแผงตั๋วในดิสคอร์ด
เมื่อบอทออนไลน์แล้ว ให้เข้าไปที่ช่อง **`🎫 • เปิดตั๋วสั่งซื้อ`** แล้วพิมพ์คำสั่ง:
```
/setup-ticket
```
บอทจะส่งข้อความ Embed พร้อมปุ่ม **[ 🎫 เปิดตั๋วสั่งซื้อ ]** ให้ลูกค้ากดได้ทันที!
