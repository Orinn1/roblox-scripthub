# 🤖 Discord AI Q&A Bot (บอทตอบคำถามอัจฉริยะ)

บอท Discord ตอบคำถามสมาชิกอัตโนมัติ ขับเคลื่อนด้วยสมองกล **Google Gemini AI** (เวอร์ชันล่าสุด เช่น `gemini-2.5-flash`) ฉลาด ตอบไว สุภาพ เป็นธรรมชาติ พร้อมระบบจดจำบริบทบทสนทนา (Conversation Memory) และฐานความรู้ (Knowledge Base) ประจำเซิร์ฟเวอร์!

---

## ✨ ฟีเจอร์เด่น (Key Features)

1. **ตอบคำถามได้หลายวิธี:**
   - 💬 **แท็กเรียกบอท:** พิมพ์ `@ชื่อบอท [ข้อความคำถาม]` ในห้องใดก็ได้
   - 🔄 **ตอบกลับ (Reply):** เมื่อบอทตอบแล้ว สมาชิกสามารถกด Reply เพื่อคุยต่อได้ทันที บอทจะจำบริบทก่อนหน้าได้
   - 📌 **ห้อง Q&A อัตโนมัติ:** ตั้งค่าห้องเฉพาะใน `.env` เพื่อให้บอทตอบทุกข้อความที่พิมพ์ในห้องนั้นโดยไม่ต้องแท็ก
   - ⚡ **Slash Commands:** รองรับคำสั่ง `/ask`, `/faq`, `/clear`, `/botinfo`
2. **🧠 ฉลาดด้วย Google Gemini:**
   - รองรับภาษาไทยสมบูรณ์แบบ ตอบสุภาพ เข้าใจภาษาพูด มีอิโมจิน่ารักๆ
   - อ่านและเข้าใจกฎของเซิร์ฟเวอร์, วิธีใช้สคริปต์, ระบบ Executor, วิธีเอาคีย์, และข้อมูล VIP จากไฟล์ `knowledge.json`
3. **💭 จดจำประวัติการคุย (Context Memory):**
   - จำข้อความก่อนหน้าได้สูงสุด 10 บทสนทนาในแต่ละห้อง คุยโต้ตอบต่อเนื่องได้เหมือนคุยกับคนจริงๆ
   - มีระบบเคลียร์ความจำอัตโนมัติเมื่อไม่มีการใช้งานเกิน 30 นาที หรือสั่ง `/clear`
4. **🛡️ ระบบความปลอดภัย & กันสแปม:**
   - ระบบ User Cooldown (เริ่มต้น 3 วินาที) ป้องกันการรัวคำถามเพื่อไม่ให้โควต้า AI หมด
   - ระบบแบ่งข้อความอัตโนมัติ (เกิน 2,000 ตัวอักษรของ Discord ไม่ตกหล่น ไม่บั๊ก)
   - ดักจับ Error สมบูรณ์ บอทไม่ดับง่าย

## 🚀 ขั้นตอนการติดตั้งและเปิดใช้งาน (Setup Guide)

### ขั้นตอนที่ 1: เตรียมคีย์ API และบอท Discord
1. **รับ Discord Bot Token & Client ID:**
   - เข้าไปที่ [Discord Developer Portal](https://discord.com/developers/applications)
   - กด **New Application** ตั้งชื่อบอท (เช่น `Blacklist AI Assistant`)
   - เมนู **General Information**: ก็อปปี้ **Application ID** (นำไปใส่ `DISCORD_CLIENT_ID`)
   - เมนู **Bot**:
     - กด **Reset Token** แล้วก็อปปี้โทเคน (นำไปใส่ `DISCORD_TOKEN`)
     - เลื่อนลงมาที่หัวข้อ **Privileged Gateway Intents** แล้ว **เปิดใช้งาน (Toggle ON):**
       - ✅ **Message Content Intent** *(สำคัญมาก! ถ้าไม่เปิด บอทจะอ่านข้อความคำถามไม่ได้)*
   - เมนู **OAuth2 -> URL Generator**:
     - ติ๊ก `bot` และ `applications.commands`
     - เลือก Permissions: `Send Messages`, `Embed Links`, `Read Message History`, `Use Slash Commands`
     - นำลิงก์ที่ได้ไปเปิดในเบราว์เซอร์เพื่อเชิญบอทเข้าเซิร์ฟเวอร์ของคุณ

2. **รับ Gemini API Key (ฟรี):**
   - เข้าเว็บ [Google AI Studio](https://aistudio.google.com/app/apikey)
   - เข้าสู่ระบบด้วยบัญชี Google แล้วกด **Create API key**
   - ก็อปปี้คีย์ที่ได้มา (นำไปใส่ `GEMINI_API_KEY`)

---

### ขั้นตอนที่ 2: ตั้งค่าไฟล์ `.env`
เปิดไฟล์ `qa-bot/.env` แล้วกรอกข้อมูล:
```env
# โทเคนและไอดีของบอท Discord
DISCORD_TOKEN=ใส่_Token_ที่นี่
DISCORD_CLIENT_ID=ใส่_Client_ID_ที่นี่
DISCORD_GUILD_ID=1548669247998140438

# คีย์ Google Gemini AI
GEMINI_API_KEY=ใส่_Gemini_API_Key_ที่นี่
GEMINI_MODEL=gemini-2.5-flash

# (ตัวเลือกเสริม) ใส่ไอดีห้องที่ต้องการให้บอทตอบคำถามทันทีโดยไม่ต้องแท็ก @บอท
QA_CHANNEL_IDS=

# คูลดาวน์การถาม (วินาที)
COOLDOWN_SECONDS=3
```

---

### ขั้นตอนที่ 3: ลงทะเบียนคำสั่ง Slash Commands
ดับเบิลคลิกไฟล์ **`deploy.bat`** (หรือรันคำสั่งด้านล่างในเทอร์มินัล):
```bash
npm run deploy
```
*ระบบจะอัปเดตคำสั่ง `/ask`, `/faq`, `/clear`, `/botinfo` เข้าไปในเซิร์ฟเวอร์ทันที*

---

### ขั้นตอนที่ 4: เปิดบอททำงาน!
- **บน Windows:** ดับเบิลคลิกที่ไฟล์ **`start.bat`** ได้ทันที (ระบบจะตรวจสอบ Node.js และดาวน์โหลด dependencies ให้โดยอัตโนมัติ)
- **หรือรันผ่านเทอร์มินัล:**
  ```bash
  cd qa-bot
  npm install
  npm start
  ```

## 🛠️ การปรับแต่งฐานความรู้ (Knowledge Base)
คุณสามารถเปิดไฟล์ **`qa-bot/knowledge.json`** เพื่อแก้ไขหรือเพิ่มข้อมูลได้ตลอดเวลา:
- **`botPersona`**: ปรับแต่งบุคลิก นิสัย และวิธีการพูดของบอท
- **`rules`**: กฎของเซิร์ฟเวอร์ที่คุณต้องการให้บอทช่วยเตือนหรือตอบเวลาคนถาม
- **`faq`**: รายการคำถามที่พบบ่อย (จะปรากฏในคำสั่ง `/faq` และเป็นข้อมูลให้อ้างอิงตอนตอบด้วย)
- **`serverName` / `websiteUrl`**: ชื่อเซิร์ฟเวอร์และลิงก์เว็บไซต์

## 📋 คำสั่ง Slash Commands ที่มีให้
| คำสั่ง | คำอธิบาย |
| :--- | :--- |
| `/chat [message]` | ชวนบอทคุยเล่น ปรึกษา ระบายความรู้สึก คุยได้ทุกเรื่องในจักรวาล ✨ |
| `/ask [question]` | ถามคำถามกับ AI อัจฉริยะโดยตรง |
| `/faq` | เปิดเมนูเลือกดูคำถามที่พบบ่อย (กดเลือกแล้วขึ้นคำตอบทันที) |
| `/clear` | ล้างประวัติการคุยกับบอท เพื่อเริ่มคุยหัวข้อใหม่แบบคลีนๆ |
| `/botinfo` | ดูสถานะของบอท, โมเดลที่ใช้, ความเร็ว Ping, เวลาออนไลน์ |

---

## 💬 วิธีการคุยเล่นกับบอท (Chatting & Banter)
- 📩 **ทักแชทส่วนตัว (Direct Message - DM):** สามารถคลิกที่ชื่อบอทแล้วส่งข้อความในแชทส่วนตัวเพื่อคุยเล่น 1-on-1 ได้ทันทีตลอด 24 ชั่วโมง โดยไม่ต้องแท็กบอท
- 🗣️ **แท็กในเซิร์ฟเวอร์:** พิมพ์ `@ชื่อบอท [ข้อความ]` ในห้องแชทใดก็ได้ บอทจะตอบกลับอย่างเป็นกันเอง
- 🔁 **คุยต่อเนื่อง (Reply):** กด Reply ตอบกลับข้อความบอทเพื่อคุยต่อได้ทันที บอทจะจำประวัติและคุยต่อเนื่องได้
- ⚡ **ใช้คำสั่ง Slash Command:** พิมพ์ `/chat [ข้อความ]` เพื่อชวนบอทคุยเล่นได้ทันที!
